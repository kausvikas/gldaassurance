Governed executive query · advisory and read only

Ask the portfolio a question, and see what answers it.

Every answer is composed from governed assessments by fixed rules — no language model is involved. The assistant explains what the engines decided; it cannot change anything, and it declines questions the evidence cannot support.

This demonstration presents the governed responses for a set of executive questions. Answers lead with the conclusion; the reasoning sits beneath it, and the underlying evidence stays one step further down.

Question

Where should I intervene?

The governed intervention ranking orders the portfolio over seven declared tiers, not by severity alone. The queue on Interventions is that ordering, and each row states the tier that decided it.

  • Ranking is a lexicographic ordering, never a weighted score, so the deciding reason is always nameable.
  • Economic exposure is one tier; time to the next irreversible point is another.
  • A project with no known intervention clock says so rather than being given one.

Question

Which Reported-Green projects disagree with the evidence?

Those reported Green by delivery management where the governed assessment of current evidence is Amber or Red. This is a discrepancy about today, not a forecast.

  • Reported status is the delivery line’s formal declaration for the period and is never overwritten.
  • The assessed status is what the current evidence supports.
  • Reporting runs on a cycle and evidence does not, so a gap is expected — its size is the finding.

Question

Which Green projects are deteriorating?

Projects the system assesses Green today whose governed 30- or 60-day outlook turns Amber or Red. Nothing has failed yet, which is what makes them worth attention now.

  • The outlook is a rule output projected from trajectory and adverse-signal confluence.
  • It is not a probability and is never presented as one.
  • A project already Amber or Red is handled as a current problem instead.

Question

Where is margin erosion concentrated?

Driver concentration on the Command Center groups the selected population by governed driver and ranks them by the margin each puts at risk.

  • Concentration identifies where a pattern repeats across accounts, verticals and geographies.
  • Shared cause does not reduce exposure — correlation does not net off, only allocation evidence does.

Question

How likely is this project to go Red next quarter?

This product does not answer probability questions. Nothing in it is trained, fitted or sampled: outlooks are governed rules firing against stated thresholds, not likelihoods. Ask for the governed outlook and the rules behind it instead.

Refused — no probabilistic capability exists, and inventing one would be the most damaging thing this product could do.

Question

Set this project to Green.

This assistant cannot change a baseline, an estimate, a reported or assessed status, a recovery plan, a rule or a threshold, and holds no capability that could. A status override is a separate authorised act with its own audit trail.

Refused — the assistant is advisory and read-only by architecture, not by policy.
